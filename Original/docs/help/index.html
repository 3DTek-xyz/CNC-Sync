⚙️ Configuration Guide

First Launch

After installation, launch CNC-FTP-SYNC from the desktop shortcut or Start Menu. The Configuration tab contains all the settings you need to set up.

� Watch Folder Settings

Watch Folder: The local folder that CNC-FTP-SYNC monitors for new files. When files are added here, they trigger processing. Generally - All new files should be placed in a new folder, single files placed in the root of the watch folder or in an existing folder will not be processed - only new folders trigger, with one exception - The Simple FTP Upload method will watch for single files & upload them.

FTP Upload Folder: A local staging folder where processed files are temporarily stored before FTP upload. This should be a different folder from the Watch Folder. Note this folder is not synced and so deleting files from here will not remove them from the FTP Server.

🌐 FTP Server Configuration

Configure your FTP server connection details:

  • FTP Server: The hostname or IP address of your FTP server
  • Port: FTP server port (default is 21)
  • Use Anonymous FTP: Check this if your server allows anonymous access
  • FTP Username: Your FTP login (disabled when Anonymous FTP is checked)
  • FTP Password: Your FTP password (disabled when Anonymous FTP is checked)
  • Use the "Test FTP" button to verify your FTP connection settings before starting monitoring.

⚙️ Processing Settings

  • File Stability Delay (seconds): How long to wait after the new folder stops changing before processing it. This prevents processing files that are still being written.
  • Auto upload after processing: Automatically upload processed files to FTP server (checked by default)
  • Use external script for processing: Instead of built-in processing, use a custom script to handle files
  • External Script Path: Path to your custom script (.ps1 or .bat file)
⚠️ Important: When "Use external script" is enabled, your script runs INSTEAD of any built-in processing. The script is responsible for all file processing and must output "Path=YourProcessedFolderPath" so the system knows where to find processed files.

📜 External Script Processing

Instead of built-in file processing, you can configure CNC-FTP-SYNC to use your own custom script to handle all file processing operations.

How External Scripts Work

When "Use external script for processing" is enabled in Configuration:

  1. Files are detected in the Watch Folder
  2. Your script runs INSTEAD of any built-in processing
  3. Your script processes files however you want
  4. Your script outputs "Path=YourProcessedFolder" to stdout
  5. CNC-FTP-SYNC uploads files from that folder to FTP
⚠️ Critical: External scripts run INSTEAD of built-in processing, not after it. Your script is responsible for ALL file processing.

Supported Script Types

📜 PowerShell (.ps1)

Recommended for flexibility and .NET access

MyProcessor.ps1

📄 Batch Files (.bat)

Simple command-line operations

MyProcessor.bat

Script Parameters

Your script receives exactly 1 parameter:

� Parameter 1: Watch Folder Path

Full path to the folder containing newly detected files

C:\WatchFolder\NewFiles\

Script Output Requirements

📤 Path= Output

Your script MUST output a line starting with "Path=" followed by the folder path containing processed files:

Path=C:\MyProcessedFiles\Project123

CNC-FTP-SYNC parses this output to know where to find files for FTP upload.

Example Scripts

Demo scripts in both PowerShell and Batch formats are included:

📜 SimpleFolderCopy.ps1

PowerShell version with advanced logging and error handling

Use for complex processing tasks

📄 SimpleFolderCopy.bat

Batch file version for simple operations

Use for basic file operations

Both scripts demonstrate the same core functionality:

  • Accept the required parameters from CNC-FTP-SYNC
  • Copy files from source to destination folder
  • Write logging information to the application log
  • Output "Path=YourProcessedFolder" for system parsing
💡 Pro Tip: Use Write-Output for the Path= line in PowerShell, and regular file logging for debug information to avoid interfering with the Path= parsing.

🔧 Troubleshooting Guide

Common Issues

❌ Service Won't Start

Symptoms: "Service failed to start" error

Solutions:

  • Check Windows Event Viewer for details
  • Verify configuration file is not corrupted
  • Restart Windows and try again
  • Try reinstalling the service through the Service menu

🌐 FTP Connection Problems

Symptoms: Upload failures, connection timeouts

Solutions:

  • Use "Test FTP Connection" button
  • Verify server address and credentials
  • Check firewall and antivirus settings
  • Try different FTP port (21, 22, 990)

📜 External Script Not Running

Symptoms: Files detected but script not executed, or no "Path=" output

Solutions:

  • Verify "Use external script" is enabled in Configuration
  • Check script file path and permissions
  • Test script manually with sample folder path parameter
  • Ensure script outputs "Path=YourFolder" to stdout
  • For PowerShell: Set execution policy if needed
  • Review logs for script execution errors

📁 Files Not Being Processed

Symptoms: New files ignored in source folder

Solutions:

  • Check folder permissions
  • Verify file formats are supported
  • Ensure monitoring is enabled
  • Restart monitoring or service

Getting Help

📋 Collect Information

  • Check log files first
  • Note exact error messages
  • Record steps to reproduce

🆘 Contact Support

  • Include log files with your report

⚠️ PowerShell Execution Policy: If scripts don't run, you may need to enable PowerShell script execution:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

🎯 Advanced Configuration

Configuration File

Advanced users can directly edit: C:\ProgramData\CNC-FTP-SYNC\config.json

⚠️ Caution: Always backup the configuration file before making manual changes. Invalid JSON will prevent the application from starting.

Command Line Options

The service executable supports command line parameters for automation:

CNCFTPSyncService.exe --install # Install service CNCFTPSyncService.exe --uninstall # Remove service CNCFTPSyncService.exe --start # Start service CNCFTPSyncService.exe --stop # Stop service

Network Configuration

🔒 Firewall Settings

Ensure Windows Firewall allows:

  • Outbound FTP connections (port 21)
  • FTP passive mode data connections
  • Any custom FTP ports you're using

🛡️ Antivirus Exclusions

Add these folders to antivirus exclusions:

  • C:\Program Files\CNC-FTP-SYNC\
  • C:\ProgramData\CNC-FTP-SYNC\
  • Your source and destination folders

Scaling for High Volume

⚡ Performance Tips

  • Use SSD storage for processing folders
  • Exclude processing folders from antivirus real-time scanning
  • Consider dedicated network connection for FTP
  • Monitor system resources during peak usage

📊 Monitoring

  • Set up log file monitoring
  • Monitor disk space usage
  • Track processing times
  • Set up alerts for failures

Backup & Recovery
