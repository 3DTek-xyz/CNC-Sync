🎯 What It Does

CBWSS-Sync monitors specified folders for new G-code projects, processes them automatically by:

  • Converting negative Y coordinates to positive values in CYC files
  • Organizing files into structured folders (NC/, AutoStickLabel/)
  • Converting files to UTF-8 encoding for compatibility
  • Uploading processed files to your FTP server
  • Providing detailed logging and status updates
