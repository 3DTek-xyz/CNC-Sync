CNC Sync

Watch local CNC export folders, process them, and deliver them to FTP reliably.

CNC Sync monitors watch folders, runs optional local processing scripts, stages the result, uploads it to FTP, and supports manual catch-up when a server or connection was unavailable.

What It Does

Watch Folders

Monitor one or more local export folders and wait for items to become stable before processing them.

Processing Setups

Use default upload mode or run local scripts to reorganize, filter, or rewrite CNC jobs before upload.

FTP Servers

Reuse named FTP server definitions across multiple watch folders, including remote base paths and credentials.

Manual Catch-Up

Compare the watch folder with the remote FTP destination and upload what is missing, reusing staged output first.
