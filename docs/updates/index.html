Software Updates

CNC Sync Update Feed

This page exists so the public update feed has a real human-visible home. Installed CNC Sync builds use the update files under this path automatically through Velopack.

https://3dtek-xyz.github.io/CNC-Sync/updates

How The App Uses It

  • Windows builds read platform-specific files such as releases.win.json.
  • Apple Silicon and Intel macOS builds each use their own macOS feed files.
  • Linux builds use the Linux feed files from the same update root.

What You Can Check

If you want to verify what version is currently advertised, these are the most useful public files:

  • Windows feed JSON
  • macOS Apple Silicon feed JSON
  • macOS Intel feed JSON
  • Linux feed JSON

Important Note

The app does not browse this directory like a website. It looks for the platform feed files directly, so those file links are the best way to confirm what the updater can currently see.
