📦 Installation & Setup

System Requirements

  • Windows 10 or Windows 11
  • Administrator privileges for installation
  • FTP server access for uploads
  • .NET 8.0 Runtime (included in installer)

Installation Steps

🔽 Step 1: Download

Download the latest installer from the main page or direct download.

🛡️ Step 2: Run as Administrator

Right-click the installer and select "Run as administrator". This is required for Windows Service installation.

📂 Step 3: Choose Installation Location

Default location: C:\Program Files\CNC-FTP-SYNC\

The installer will also create:

  • C:\ProgramData\CNC-FTP-SYNC\ - Configuration files
  • C:\Program Files\CNC-FTP-SYNC\UserScripts\ - Custom scripts

🎯 Step 4: Service Installation

The installer automatically:

  • Installs the Windows Service
  • Creates desktop shortcut
  • Adds Start Menu entries
  • Sets up UserScripts folder with demo script
⚠️ Important: If you see "Service failed to start" during installation, this is normal on first install. Launch the GUI and start the service manually.

⚙️ Configuration Guide

First Launch

After installation, launch CNC-FTP-SYNC from the desktop shortcut or Start Menu.

🗂️ Folder Settings

Source Folder: Where you drop new G-code projects

Destination Folder: Where processed files are organized

Archive Folder: Where completed projects are stored

🌐 FTP Configuration

Configure your FTP server details:

  • Server: Your FTP server address
  • Username: FTP login username
  • Password: FTP login password
  • Port: Usually 21 (default)
  • Upload Path: Remote directory path

🔄 Processing Options

  • Auto-start monitoring: Begin watching folders immediately
  • Delete source after processing: Clean up original files
  • Enable logging: Detailed operation logs
💡 Pro Tip: Use the "Test FTP Connection" button to verify your settings before starting monitoring.

Service vs Standalone Mode

🔧 Service Mode (Recommended)

  • Runs automatically at startup
  • Works without user login
  • Continues running in background
  • Professional deployment

👤 Standalone Mode

  • Only runs when GUI is open
  • Requires user to be logged in
  • Good for testing/development
  • Manual control

📜 UserScripts Guide

UserScripts let you add custom processing logic to CNC-FTP-SYNC. Scripts run after G-code processing but before FTP upload.

Script Location

Place your scripts in: C:\Program Files\CNC-FTP-SYNC\UserScripts\

Supported Script Types

📜 PowerShell (.ps1)

Most flexible option with full .NET access

MyScript.ps1

📄 Batch Files (.bat/.cmd)

Simple command-line operations

MyScript.bat

⚡ Executables (.exe)

Compiled programs for complex operations

MyProgram.exe

Script Parameters

Your script receives exactly 3 parameters:

📥 Parameter 1: Input Folder Path

Full path to the processed G-code folder

C:\ProcessedProjects\MyProject\

📤 Parameter 2: Expected Output Path

Where your script should place the final result

C:\ReadyForUpload\MyProject\

📋 Parameter 3: Project Name

The name of the current project

MyProject

Demo Script Example

A demo script SimpleFolderCopy.ps1 is included:

param( [string]$InputFolderPath, [string]$OutputFolderPath, [string]$ProjectName ) # Your custom processing logic here Write-Host "Processing project: $ProjectName" Write-Host "Input: $InputFolderPath" Write-Host "Output: $OutputFolderPath" # Copy files with your modifications Copy-Item -Path $InputFolderPath -Destination $OutputFolderPath -Recurse -Force
⚠️ Important: Your script MUST create the output folder and place files there. CNC-FTP-SYNC will upload whatever is in the output folder.

Script Execution Order

  1. CNC-FTP-SYNC processes G-code files
  2. Your UserScript runs with the processed files
  3. CNC-FTP-SYNC uploads your script's output to FTP
  4. Files are archived for future reference

🔧 Troubleshooting Guide

Common Issues

❌ Service Won't Start

Symptoms: "Service failed to start" error

Solutions:

  • Run GUI as Administrator
  • Check Windows Event Viewer for details
  • Verify configuration file is not corrupted
  • Restart Windows and try again

🌐 FTP Connection Problems

Symptoms: Upload failures, connection timeouts

Solutions:

  • Use "Test FTP Connection" button
  • Verify server address and credentials
  • Check firewall and antivirus settings
  • Try different FTP port (21, 22, 990)

📜 UserScript Not Running

Symptoms: Files processed but script not executed

Solutions:

  • Check script file permissions
  • Verify script syntax (test manually)
  • Review log files for script errors
  • Ensure PowerShell execution policy allows scripts

📁 Files Not Being Processed

Symptoms: New files ignored in source folder

Solutions:

  • Check folder permissions
  • Verify file formats are supported
  • Ensure monitoring is enabled
  • Restart monitoring or service

Getting Help

📋 Collect Information

  • Check log files first
  • Note exact error messages
  • Record steps to reproduce
  • Check Windows Event Viewer

🆘 Contact Support

  • Include log files with your report
  • Describe your configuration
  • Mention Windows version
  • Provide error screenshots
⚠️ PowerShell Execution Policy: If scripts don't run, you may need to enable PowerShell script execution:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

🎯 Advanced Configuration

Configuration File

Advanced users can directly edit: C:\ProgramData\CNC-FTP-SYNC\config.json

⚠️ Caution: Always backup the configuration file before making manual changes. Invalid JSON will prevent the application from starting.

Command Line Options

The service executable supports command line parameters for automation:

CNCFTPSyncService.exe --install # Install service CNCFTPSyncService.exe --uninstall # Remove service CNCFTPSyncService.exe --start # Start service CNCFTPSyncService.exe --stop # Stop service

Network Configuration

🔒 Firewall Settings

Ensure Windows Firewall allows:

  • Outbound FTP connections (port 21)
  • FTP passive mode data connections
  • Any custom FTP ports you're using

🛡️ Antivirus Exclusions

Add these folders to antivirus exclusions:

  • C:\Program Files\CNC-FTP-SYNC\
  • C:\ProgramData\CNC-FTP-SYNC\
  • Your source and destination folders

Scaling for High Volume

⚡ Performance Tips

  • Use SSD storage for processing folders
  • Exclude processing folders from antivirus real-time scanning
  • Consider dedicated network connection for FTP
  • Monitor system resources during peak usage

📊 Monitoring

  • Set up log file monitoring
  • Monitor disk space usage
  • Track processing times
  • Set up alerts for failures

Backup & Recovery

💾 What to Backup

  • C:\ProgramData\CNC-FTP-SYNC\config.json - Your configuration
  • C:\Program Files\CNC-FTP-SYNC\UserScripts\ - Custom scripts
  • Archive folder contents - Processed projects

🔄 Recovery Process

  1. Reinstall CNC-FTP-SYNC
  2. Stop the service
  3. Restore configuration and scripts
  4. Start the service
  5. Verify configuration in GUI
